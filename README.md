Customer Shopping Behaviour Analysis

An end-to-end data analytics project analyzing customer shopping behaviour using Python, PostgreSQL, SQL, and Power BI.

The project covers the complete analytics workflow — from raw customer data cleaning and exploratory data analysis to SQL-based business analysis and an interactive Power BI dashboard.

📌 Project Overview

The objective of this project is to analyze customer purchasing behaviour and extract meaningful business insights from customer transaction data.

The workflow consists of:

Raw Data → Data Cleaning → Exploratory Data Analysis → PostgreSQL → SQL Analysis → Power BI Dashboard

The analysis focuses on areas such as customer spending, subscription behaviour, purchase patterns, discounts, product categories, and customer demographics.

📂 Project Workflow
1. Data Cleaning

The raw customer dataset was imported into Python and prepared for analysis.

The cleaning process included:

Handling missing values
Checking and removing duplicate records
Correcting data types
Standardizing categorical values
Renaming columns where required
Checking for inconsistent or invalid data
Preparing the final dataset for database analysis
2. Exploratory Data Analysis (EDA)

After cleaning the data, exploratory analysis was performed to understand customer behaviour and identify important patterns.

The analysis included:

Customer demographic analysis
Purchase amount distribution
Product category analysis
Age-group analysis
Subscription status analysis
Discount usage
Purchase frequency
Customer spending behaviour
Relationships between different customer attributes

Visualizations were created using Matplotlib and Seaborn to identify trends and patterns in the dataset.

3. PostgreSQL & SQL Analysis

The cleaned dataset was loaded into PostgreSQL for structured database analysis.

SQL queries were written to answer business-oriented questions, including:

Which product categories generate the most revenue?
Do subscribed customers spend more than non-subscribed customers?
What is the average spending by customer segment?
Which categories have the highest purchase frequency?
How does discount usage affect purchasing behaviour?
What are the characteristics of high-value customers?
How does customer behaviour vary across different demographic groups?

SQL was used to perform operations such as:

GROUP BY
ORDER BY
WHERE
HAVING
Aggregate functions
CASE statements
Subqueries
Joins
📊 Power BI Dashboard

The final cleaned data and analytical results were used to create an interactive Power BI dashboard.

The dashboard provides an overview of:

Total Revenue
Average Purchase Amount
Number of Customers
Subscription Status
Product Category Performance
Customer Demographics
Purchase Behaviour
Discount Usage

Interactive slicers and visualizations allow users to explore the data across different customer segments and categories.
